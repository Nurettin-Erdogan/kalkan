# Güvenlik Politikası

## Desteklenen sürümler

Güvenlik düzeltmeleri `main` dalına uygulanır.

## Güvenlik açığı bildirme

Herkese açık issue açmayın. Güvenlik açığını [GitHub Security Advisories](https://github.com/Nurettin-Erdogan/kalkan/security/advisories/new) üzerinden bildirin.

## Kapsam

Tarayıcı içi risk analizi, OCR ve bağımlılıklar kapsam içindedir. Kalkan bir risk değerlendirme aracıdır; kesin güvenlik garantisi vermez. Gerçek kişisel mesaj içeriklerini raporlara eklemeyin.
